# Kế hoạch thực hiện đã bắt đầu

1. Nền tảng local: runtime, source, schema, database, auth, kiểm tra tự động.
2. Một luồng xuyên suốt: bài học → chấm server → tiến độ → lịch ôn → đăng nhập lại.
3. CMS: soạn bằng form, review, publish, revision, import/export và audit.
4. Giao diện Public/Learner/Admin responsive và kiểm tra trình duyệt.
5. Mở rộng nội dung theo ma trận nhập môn–HSK 4, kiểm tra ngôn ngữ, audio và chất lượng.
6. Cloud adapter, xác minh tài khoản và dự toán; staging với cùng bộ test.
7. Backup/restore ngoài AWS, load test, privacy, vận hành và bàn giao.

Không tự dừng ở mốc UI. Mốc hoàn thành dự án vẫn cần toàn bộ HSK 4 và triển khai thật. Dependency bên ngoài ghi BLOCKED cụ thể; tiếp tục các phần độc lập.
